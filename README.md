## Sweet&Sugar - Curso Desarrollo Web Coder House

Este Repositorio fue realizado por Vanessa Ramos para Sweet&Sugar, una dulcería ubicada en Cabudare, edo. Lara, Venezuela.

Fue utilizado HTML5, CSS, SASS

Carpetas:

- Img: contiene todas las imágenes utilizadas en la web.
- Css: Contiene todos los estilos de la web (style.css) y donde se normaliza la web (normalize.css).
- Scss: Contiene todos los archivos .scss que se utilizan para aplicar SASS al proyecto y así ordenar mejor la hoja de estilos (style.css)
- Pages: Dodne se encuentran las páginas del proyecto (Postres, Dulcería, Conócenos y Contáctanos), menos el "index.html" (Página de Inicio).

Archivos:

- index.html
- 404.html
- README.md
- .gitignore
- package-lock.json
- package.json
